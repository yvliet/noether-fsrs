# Spaced Repetition (FSRS) for Flint

State-of-the-art Free Spaced Repetition Scheduler (FSRS) flashcard review system built right inside Flint.

## 1. Installation
---

Install directly within Flint from the **Community Extensions Marketplace** or place into your Hearth's `.flint/extensions/fsrs-spaced-repetition/` folder.

## 2. Building Locally
---

```bash
npm install
npm run build
```
